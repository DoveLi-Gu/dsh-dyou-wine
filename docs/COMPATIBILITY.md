# 兼容矩阵

本版为 `0.1.0-alpha.14`，仅同步文档和包版本，不扩大运行时兼容范围。四份运行入口／媒体已与 Alpha.13 基线逐字节比对一致；本版类型检查、69 项单元测试、构建、37 项浏览器测试、市场元数据与 21 文件包白名单检查通过，详见 [TESTING.md](TESTING.md) Alpha.14 节。本次未重跑真实 DSH、60 秒性能对照或物理扬声器验收，真实宿主功能证据沿用单列的 Alpha.13 历史。

Alpha.13 历史：媒体拆为包内 PNG／MP3，通过 DSH `webServer` 同源固定路由加载，真实运行入口和媒体进入 Git；已通过 69 项测试、37 浏览器、类型检查、构建、21 文件包检查及真实隔离 DSH 媒体与动画验收。客户端入口 80,268 bytes。dsh.pub 本地静态检查与远程收录分别记录于 [MARKETPLACE.md](MARKETPLACE.md)，不将其作为 Alpha.14 的新验收证据。

静态媒体服务只用于 Web HTTP 载体，不能据此宣称支持 Desktop／file://。依赖宿主的标准 `webServer` 服务；媒体来自安装包，运行时不依赖外部音乐或图片服务器。

Alpha.11 历史：47 单测、36 浏览器及 18 文件包检查通过，并在真实隔离 DSH 中录制双效果、验证固定节奏与两轴反弹；Alpha.10 的完整宿主 BGM 检验与性能记录另保留为历史。本轮不把旧版本专项记录冒充重新执行的结果。

Alpha.10 历史：运行时沿用 Alpha.9，新增命名／图标／中英文发现信息并修复验收脚本；已通过干净副本安装、47 单测、36 浏览器测试、构建、18 文件包检查和真实隔离 DSH 运行，双效果 1261 帧相位误差 0 ms，音乐、飞行反弹与退出清理通过。证据保留在 TESTING.md 的 Alpha.10 节及 `.qa/release-final/`。下表保留当时 Alpha.9 已安装版本的事实。Alpha.13 日常实例更新与内置浏览器预览单独记录于 `.qa/deployment/static-alpha13/installation.json`，不能从隔离测试推断；Alpha.14 尚未更新日常实例。

适配范围：DSH `0.2.0-rc.2`，桌面 Chromium 浏览器中的 Web 客户端。`engines.dsh` 锁定适配版本，本身不证明运行验收通过。

已交付版本 `0.1.0-alpha.9` 将原梗 BGM 改为内置 MP3，移除左下角视频并保留来源跳转链接。两个独立效果、固定 120 BPM、扩大文字与图像候选覆盖及简洁面板沿用 Alpha.8。Alpha.9 类型检查、42 项单元测试、36 项浏览器测试、构建、包检查与真实隔离 DSH 验收通过；日常安装以交付记录为准，结果见 [测试记录](TESTING.md)。历史版本通过结论不替代当前候选重新验收。

Alpha.8 历史：本机 37 项单元测试、35 项浏览器测试、构建和 14 个公开文件检查通过；真实隔离宿主双效果采样 1260 帧、500 ms 周期、相位误差 0 ms。原版官方 iframe 播放器的媒体状态仅适用于 Alpha.8，不作为本版内置 MP3 的播放证据。

Alpha.7 历史：本机 37 项单元测试、31 项浏览器测试与真实隔离 DSH 检查通过；双效果采样 605 帧、500 ms 周期、最大相位差 0 ms。详见 TESTING.md 的 Alpha.7 历史节与 `.qa/alpha.7/`，这些不是 Alpha.9 的通过证据。

版本适配器按语义标签、可见组件及 `data-chat-flow`／`data-streaming` 等实际标记识别目标，不依赖构建后的 CSS 哈希。扩大候选后仍不对所有 DOM 节点强制施加动画：父级带动的子区域计入覆盖，滚动根、原生弹层、已有变换冲突、固定定位冲突与交互保护区可被主动排除。玩偶使用独立浮层，不依赖文字覆盖率；插件控制入口与面板排除在扫描之外。新增 DSH 版本需更新适配器与验收证据，再扩大声明。
