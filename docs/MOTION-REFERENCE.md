# 动效参考与观察边界

来源：[Bilibili 视频 BV19iHk6PEmh](https://www.bilibili.com/video/BV19iHk6PEmh/)。本轮开发通过内置浏览器实际查看可播放画面，用于判断动作方向；不把标题或静态封面当作动效证据。

## 观察到的节奏

- 一组娃娃基本使用同一相位，压矮和拉高的时机一致。
- 底部基本留在同一位置，形变集中在高度；视觉重心是明显的周期性压矮／拉高。
- 单个周期连贯，没有 Alpha.2 那种离地后多次递减回跳的组织方式；用户进一步明确，所需的是固定循环，不要求每次动作都对齐歌曲鼓点。
- 横向变化用于陪衬纵向形变，不应造成整组忽宽忽窄或元素各自乱晃。

这些描述来自本轮可见画面的定性观察。没有测得原视频的准确 BPM、音画偏移、逐帧缩放比例或精确曲线，也没有确认其制作软件、算法或素材来源，不编造对应数值。

## 本插件的实现选择

Alpha.4 延续每拍一个平滑周期的形变，全部目标同相位；固定安全目标的底部，取消离地位移、旋转、DOM 顺序错相与四拍强弱变化。纵向压矮／拉高主导节奏，横向作较小反相补偿。父子只选一个自有形变根，避免重复叠加。曲线参数由插件自行设计，见 [设计基线](../DESIGN.md)，不声称是原视频的逐帧还原。

浏览器原生 WAAPI 以统一时基连续播放。性能保护只限制参与数量，不自动修改周期、幅度或曲线；控件保护不因变形边界反复经过静止指针而自激。固定设置下应观察多个周期的重复性，不能只检查单拍尺寸。

Alpha.9 简洁面板固定为 120 BPM，不声称自动匹配原视频或歌曲。验收需观察完整周期并比较群体节奏；截图、目标计数或类型检查均不能单独证明观感一致。
